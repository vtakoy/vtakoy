# Анализатор документов с GigaChat RAG

Система для анализа документов и ответов на вопросы с использованием векторного поиска и LLM на базе GigaChat.

## Возможности

- Полный анализ документов в форматах `.docx`, `.pdf`, `.txt`, `.xlsx`, `.xls`
- Извлечение информации из документов с помощью RAG (Retrieval-Augmented Generation)
- Ответы на вопросы по содержимому документов на русском языке
- Структурированные ответы с указанием источников информации
- Полное чтение Excel файлов (все листы и все строки)
- Улучшенное чтение Word документов (включая метаданные, колонтитулы)
- Поддержка PDF документов с извлечением текста и метаданных
- Поддержка работы как с публичным API GigaChat, так и с внутренним контуром Банка

## Установка и запуск

### 1. Клонирование репозитория и настройка окружения

```bash
# Клонируйте репозиторий
git clone <URL_репозитория>
cd FileAnalyzer

# Создайте виртуальное окружение
python -m venv .venv

# Активируйте виртуальное окружение
# Windows:
.venv\Scripts\activate
# Linux/Mac:
# source .venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка учетных данных GigaChat

Создайте файл `.env` в корневой директории и добавьте в него учетные данные GigaChat:

```
# Обязательные параметры - учетные данные GigaChat
GIGACHAT_CLIENT_ID=ваш_client_id
GIGACHAT_CLIENT_SECRET=ваш_client_secret

# Местоположение для работы с GigaChat API
# home - для работы дома (вне контура банка)
# work - для работы в контуре банка
WORK_LOCATION=home

# Опция 1: Использование переключателя режимов работы
# INTERNAL_NETWORK=true - для работы внутри контура банка
# INTERNAL_NETWORK=false - для работы с публичным API (по умолчанию)
INTERNAL_NETWORK=false

# Опция 2: Явное указание URL-адресов API (приоритетнее опции 1)
# Если вы хотите явно задать URL-адреса, укажите следующие параметры:
# GIGACHAT_API_URL=https://gigachat.devices.sberbank.ru/api/v1
# GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
```

**Важно**: Если в файле `.env` заданы параметры `GIGACHAT_API_URL` и `GIGACHAT_AUTH_URL`, они будут использоваться независимо от значения `INTERNAL_NETWORK`.

### 3. Подготовка документов для анализа

Поместите документы для анализа в директорию `documents/`. Поддерживаются следующие форматы:
- `.docx` (Microsoft Word) - полное чтение включая метаданные и колонтитулы
- `.pdf` (PDF документы) - извлечение текста и метаданных со всех страниц
- `.txt` (Текстовые файлы) - полное чтение содержимого
- `.xlsx`, `.xls` (Microsoft Excel) - чтение всех листов и всех строк данных

### 4. Запуск приложения

#### Веб-интерфейс
```bash
python app.py
```
После запуска приложение будет доступно по адресу http://localhost:5000/

#### Консольное приложение
```bash
python main.py
```

## Использование

### Запросы для анализа документов

Чтобы проанализировать документы, запрос должен начинаться с фразы "Требуется информация", например:

```
Требуется информация о процессе создания заказа
```

Система найдет соответствующую информацию в загруженных документах и предоставит структурированный ответ с указанием источников.

### Запросы к GigaChat без анализа документов

Если запрос не начинается с "Требуется информация", он будет напрямую направлен к GigaChat без поиска в документах.

## Особенности обработки документов

- **Word (.docx)**: извлекаются метаданные, основной текст, таблицы и колонтитулы
- **Excel (.xlsx, .xls)**: извлекаются данные из всех листов книги
- **PDF (.pdf)**: извлекается текст со всех страниц и метаданные документа
- **TXT (.txt)**: извлекается весь текст файла

## Переключение между режимами работы

Система поддерживает два режима работы с GigaChat:

1. **Режим публичного API** (по умолчанию):
   - Используется для работы вне контура банка
   - URL аутентификации: `https://auth.gigachat.io/oauth/token`
   - URL API: `https://gigachat.io/api/v1`

2. **Режим внутреннего контура банка**:
   - Используется внутри контура банка (Enablers)
   - URL аутентификации: `https://sm-auth-sd.prom-88-89-apps.ocp-geo.ocp.sigma.sbrf.ru/api/v2/oauth`
   - URL API: `https://gigachat.devices.sberbank.ru/api/v1`

Для переключения между режимами измените параметр `INTERNAL_NETWORK` в файле `.env`:
```
# Для работы внутри контура банка
INTERNAL_NETWORK=true

# Для работы с публичным API
INTERNAL_NETWORK=false
```

## Решение проблем

### Проблемы с установкой библиотек и конфликтами версий

Если при запуске приложения возникают ошибки, связанные с несовместимостью версий, выполните следующие шаги:

```bash
# Создайте новое виртуальное окружение
python -m venv .venv_new

# Активируйте новое окружение
# Windows:
.venv_new\Scripts\activate
# Linux/Mac:
# source .venv_new/bin/activate

# Установите точные версии зависимостей из requirements.txt
pip install -r requirements.txt
```

При использовании фиксированных версий в requirements.txt приложение должно работать корректно.

### Проблемы с SSL-сертификатами

В проекте по умолчанию отключена проверка SSL-сертификатов для работы с GigaChat API. Если возникают проблемы с SSL:
- Обновите корневые сертификаты в вашей системе
- Используйте параметр `verify_ssl=False` при создании клиентов

### Ошибки подключения к API GigaChat

Если вы видите ошибки типа `[Errno 11001] getaddrinfo failed` или `[Errno 11002] getaddrinfo failed`:

1. **Проверьте параметр WORK_LOCATION:**
   - Если вы находитесь **внутри контура банка** (на работе):
     ```
     WORK_LOCATION=work
     ```
   
   - Если вы находитесь **вне контура банка** (дома):
     ```
     WORK_LOCATION=home
     ```

   Система автоматически выберет правильные URL-адреса для каждого случая.

2. **Если проблемы с подключением сохраняются:**
   ```
   # Для ручного указания URL-адресов API
   GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
   GIGACHAT_BASE_URL=https://gigachat.devices.sberbank.ru/api/v1
   ```
