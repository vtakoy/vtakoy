# Анализатор документов с GigaChat RAG

Система для анализа документов и ответов на вопросы с использованием векторного поиска и LLM на базе GigaChat.

## Возможности

- Анализ документов в форматах `.docx`, `.txt`, `.xlsx`, `.xls`
- Извлечение информации из документов с помощью RAG (Retrieval-Augmented Generation)
- Ответы на вопросы по содержимому документов на русском языке
- Структурированные ответы с указанием источников информации

## Установка и запуск

### 1. Клонирование репозитория и настройка окружения

```bash
# Клонируйте репозиторий
git clone <URL_репозитория>
cd FileAnalyzer

# Создайте виртуальное окружение
python -m venv .venv

# Активируйте виртуальное окружение
# Windows:
.venv\Scripts\activate
# Linux/Mac:
# source .venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка учетных данных GigaChat

Создайте файл `.env` в корневой директории и добавьте в него учетные данные GigaChat:

```
GIGACHAT_CLIENT_ID=ваш_client_id
GIGACHAT_CLIENT_SECRET=ваш_client_secret
```

### 3. Подготовка документов для анализа

Поместите документы для анализа в директорию `documents/`. Поддерживаются следующие форматы:
- `.docx` (Microsoft Word)
- `.txt` (Текстовые файлы)
- `.xlsx`, `.xls` (Microsoft Excel)

### 4. Запуск приложения

```bash
python app.py
```

После запуска приложение будет доступно по адресу http://localhost:5000/

## Использование

### Запросы для анализа документов

Чтобы проанализировать документы, запрос должен начинаться с фразы "Требуется информация", например:

```
Требуется информация о процессе создания заказа
```

Система найдет соответствующую информацию в загруженных документах и предоставит структурированный ответ с указанием источника.

### Запросы к GigaChat без анализа документов

Если запрос не начинается с "Требуется информация", он будет напрямую направлен к GigaChat без поиска в документах.

## Решение проблем

### Проблемы с установкой библиотек и конфликтами версий

Если при запуске приложения возникает ошибка `ImportError: cannot import name 'UsageMetadata'` или другие ошибки, связанные с несовместимостью версий, выполните следующие шаги:

```bash
# Создайте новое виртуальное окружение
python -m venv .venv_new

# Активируйте новое окружение
# Windows:
.venv_new\Scripts\activate
# Linux/Mac:
# source .venv_new/bin/activate

# Установите точные версии зависимостей из requirements.txt
pip install -r requirements.txt
```

При использовании фиксированных версий в requirements.txt приложение должно работать корректно.

### Проблемы с SSL-сертификатами

В проекте по умолчанию отключена проверка SSL-сертификатов для работы с GigaChat API. Если возникают проблемы с SSL:
- Обновите корневые сертификаты в вашей системе
- Используйте параметр `verify_ssl=False` при создании клиентов

### Ошибка ImportError для langchain-gigachat

Убедитесь, что библиотека установлена:

```bash
pip install langchain-gigachat>=0.3.10
```

Если проблема сохраняется, установите библиотеку из репозитория GitHub:

```bash
pip install git+https://github.com/ai-forever/gigachat-api.git#subdirectory=langchain
```
